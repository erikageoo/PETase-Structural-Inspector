# PETase-Structural-Inspector
Structural analysis and PyMOL visualization scripts for PETase enzymes

## Overview
This repository contains automated PyMOL scripts to load, clean, and highlight the catalytic residues (Ser-His-Asp triad) of plastic-degrading enzymes, setting the stage for in silico protein engineering

## Requirements
- [PyMOL](https://pymol.org/) installed locally

## Usage
1. Open PyMOL.
2. Run the script from the command line or PyMOL terminal:
   text
   @inspect_petase.pml
